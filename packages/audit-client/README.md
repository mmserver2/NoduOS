# @noduos/audit-client

Package transversal mínimo da fundação estrutural do NoduOS.

## Limites

- Não contém regra comercial.
- Não decide autorização final.
- Não acessa banco.
- Não importa módulo comercial.
- Não transporta segredo bruto.
- Não transporta evidência bruta.
- Não cria endpoint.
- Não inicia serviço.
