# Core Platform

Núcleo obrigatório do NoduOS.

## Responsabilidade estrutural

O Core Platform autentica, contextualiza, autoriza, licencia, audita, protege e conecta.

## Limite desta etapa

Esta pasta contém apenas esqueleto estrutural e tipos conceituais.

Não há:

- autenticação real;
- sessão real;
- banco;
- migration;
- endpoint funcional;
- serviço iniciado;
- módulo comercial;
- regra operacional de domínio comercial.
