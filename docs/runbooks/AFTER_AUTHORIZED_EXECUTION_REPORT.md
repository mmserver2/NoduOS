# Relatório para retorno ao chat central após execução futura autorizada

Trazer ao chat central:

- conteúdo do manifesto pré-etapa;
- conteúdo do manifesto pós-etapa;
- caminho do log de auditoria;
- resumo de arquivos criados;
- resumo de candidatos criados por divergência;
- confirmação de que /opt/noduos/current não foi alterado;
- confirmação de que /opt/noduos/releases não foi alterado;
- saída final do script;
- qualquer falha controlada, se houver.
